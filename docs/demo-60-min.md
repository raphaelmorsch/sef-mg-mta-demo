# Roteiro substituído

O roteiro principal agora está em [Apresentação integrada — 60 minutos](apresentacao-integrada-60-min.md).

A apresentação inteira dura uma hora. A demonstração ocupa apenas **18–43 min (25 minutos)**, com alternativa de corte para 20 minutos. O restante cobre contexto, boas práticas, fluxo do desenvolvedor, governança e perguntas.

O [guia detalhado](guia-apresentador.md) serve para ensaio e consulta, não para executar integralmente durante o evento.
